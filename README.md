# CAPGIFT — ふるさと納税、あといくら

年収と家族を入れると、ふるさと納税で自己負担2,000円に収まる寄付の上限の目安を計算する。今年もう寄付した額を引いた残りの金額で、楽天ふるさと納税の返礼品をそのまま探せる。

## 🔗 リンク

- 遊ぶ: https://capgift.t-of.workers.dev/（Cloudflare。公開はまだ）
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 今年の年収（額面）と、配偶者・高校生の子・大学生の子の人数を入れる。
2. 上限の目安と、今年あといくら寄付できるかがその場で出る。社会保険料ははじめ年収の15%で見積もり、折りたたみを開けば手で入れられる。
3. 残りが1,000円以上あると「残りで選ぶ」が出る。金額の帯（1品／2品に分ける／1万円前後）と種類（お米・肉・魚介・果物・日用品）を選ぶと、楽天ふるさと納税の検索結果（寄付額の範囲で絞ったもの）へのリンクになる。

計算式・出典は画面の「計算のしかたと出典」から見られる。目安であり、正確な額は市区町村・税務署・税理士に確認すること。

## お金の取り方（紹介料）

「残りで選ぶ」のリンクは、楽天アフィリエイトのリンクで包んだ、楽天ふるさと納税の検索結果への URL（`https://search.rakuten.co.jp/search/event/<キーワード>/?ev=40&min=<下限>&max=<上限>` を `https://hb.afl.rakuten.co.jp/hgc/<アフィリエイトID>/?pc=…&m=…` で包んだもの）。押した先で寄付があると、T.OF... に紹介料が入ることがある。API は使わず、ブラウザの中の計算だけで完結する（最初の版）。

## データ

端末の外には送らない。localStorage に保存するのは次の2つ（キーは `capgift.` で始まる）。

| キー | 中身 |
|---|---|
| `capgift.inputs` | `{ v: 1, year, income, spouse, hs, uni, social, donated, genre }`。`income`（年収、万円）・`social`（社会保険料、万円。`null` なら年収の15%で見積もり）・`donated`（今年もう寄付した額、円）。`year` が今の年と違えば `donated` だけ 0 に戻す |
| `capgift.settings` | `{ v: 1, sound }` |

### アフィリエイト ID

楽天アフィリエイトの ID は `calc.js` の `AFFILIATE_ID` 定数（1か所）に、オーナーが楽天アフィリエイトの管理画面で発行した値を入れてある。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

計算ロジックの自己チェック（`docs/private/specs/capgift.md`「8.」の値を確かめる）:

```sh
node test.mjs
```
